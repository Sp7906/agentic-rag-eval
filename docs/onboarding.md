# Onboarding Guide

## First week
New joiners receive their laptop on day 1. Each new joiner is assigned an onboarding buddy for the first 3 months. Security awareness training must be completed within 7 days of joining.

## Probation
The probation period is 6 months. A confirmation review is held with the manager in the last month of probation.

## 30-60-90 plan
Managers prepare a 30-60-90 day plan with goals for each new joiner during week one.
