# Information Security Policy

## Passwords and MFA
Passwords must be at least 14 characters long and are changed every 180 days. Multi-factor authentication is mandatory on all company accounts.

## Lost or stolen devices
A lost or stolen laptop or phone must be reported within 1 hour to security@northwind.example. The security team will lock the device remotely.

## Data handling
Company data must not be stored in personal cloud storage. Suspected phishing emails should be reported using the Report Phishing button in the mail client.
